# Lumi V4 Alpha Release Checklist

A tag is not an alpha release candidate until every mandatory item below is verified.

## Automated gates

- [ ] Ubuntu full Python/API/security/developer suite green
- [ ] macOS full Python/API/security/developer suite green
- [ ] deterministic RAG gate green
- [ ] deterministic memory gate green
- [ ] `lumi-core doctor --initialize --skip-model` green
- [ ] deterministic process-level acceptance green
- [ ] Swift build green
- [ ] Swift tests green
- [ ] `Lumi.app` package builds
- [ ] ad-hoc `codesign --verify --deep --strict` green

## Target Mac acceptance

- [ ] fresh install through `scripts/install_lumi.sh`
- [ ] intended Ollama chat model installed and responds
- [ ] intended embedding model installed and responds
- [ ] `lumi-core doctor --strict --full-check` green
- [ ] SwiftUI chat streams a non-fallback response
- [ ] stop generation works
- [ ] document import + citation works
- [ ] durable memory create/recall/edit/delete works
- [ ] approval-gated tool write works and denial works
- [ ] Developer Agent plan review works on a disposable worktree
- [ ] Developer Agent never modifies the running Lumi checkout

## Data safety

- [ ] verified manual backup created
- [ ] restore rehearsal completed on a copy, not the only live database
- [ ] pre-restore backup behavior verified
- [ ] database full integrity check green after restore

## Security

- [ ] no secrets in Git history/diff
- [ ] loopback mode tested without API key
- [ ] authenticated mode tested with Keychain API key
- [ ] non-loopback bind without API key is rejected
- [ ] Developer Agent GitHub token remains environment-only

## Distribution

- [ ] version/tag matches release notes
- [ ] release artifacts generated by GitHub Actions
- [ ] SHA-256 hashes recorded in release notes
- [ ] alpha limitations explicitly stated

Developer ID signing/notarization is required before distributing Lumi as a normal macOS application outside controlled alpha testing.
